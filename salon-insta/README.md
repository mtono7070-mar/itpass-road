# サロン向け Instagram 投稿制作ツール（操作説明）

美容・エステサロンの「4投稿セット（お試し）」「月8投稿（継続）」を、少ない時間で制作・確認・納品するための道具です。

- **費用：0円**（Python だけで動きます。有料APIや外部サービスは使いません）
- **できること**：店舗情報 → 投稿テーマ・見出し・画像構成案・キャプション・ハッシュタグを一括作成 → 表現チェック → 人間が確認 → 納品データ（CSV・Markdown・Canva用CSV）
- **しないこと**：Instagramへの自動投稿、施術効果・料金・口コミ・実績の創作

---

## 0. 準備（最初の1回だけ）

1. Python 3.11 以上が必要です。ターミナルで `python3 --version` を実行して確認します。
   - Windows では `python3` を `python` に読み替えてください。
2. ターミナルでこのフォルダに移動します。

   ```bash
   cd salon-insta
   ```

3. 動作確認として、架空サロンのサンプルを作ります。

   ```bash
   python3 salon.py sample
   ```

   `clients/sample-salon/orders/…/確認用.md` に6本の投稿案ができます。
   完成例は [samples/output/サンプル投稿_確認用.md](samples/output/サンプル投稿_確認用.md) でも見られます。

## 1. 新しいお客様（店舗）を登録する

```bash
python3 salon.py new-client salon-a
```

- `salon-a` は顧客ID です（半角英数字。店名ローマ字などでOK）。
- `clients/salon-a/` フォルダができます。

```
clients/salon-a/
├── client.toml   ← 店舗情報（ヒアリング内容を書く）
├── photos/       ← 店舗から受け取った写真の置き場所
└── orders/       ← 注文ごとの制作物
```

### client.toml の書き方

テキストエディタ（メモ帳、VS Code など）で開き、`""` の中を書き換えます。

| 項目 | 書く内容 | 注意 |
|---|---|---|
| name / area / access | 店名・地域・アクセス | area はハッシュタグに使います |
| concept / features | コンセプト・特徴 | **店舗から聞いた事実だけ** |
| tone | やさしい / 上品 / 親しみ | 文章の締めと絵文字が変わります |
| menus | メニュー名・時間・料金・説明・お悩み | 料金が空欄なら投稿に載せません |
| faqs / staff | よくある質問・スタッフ | スタッフは本人の掲載同意が必要 |
| hashtags.max | 1投稿のタグ数 | 初期値5。Instagramの仕様に合わせて変更 |
| privacy.photo_consent | 写真の使用許諾を確認したら true | false だと全投稿に確認事項が付きます |
| privacy.ng_words | 店舗が使ってほしくない言葉 | 使われるとNG警告になります |

> 「シミが消える」「痩せる」など効果を断定する言葉は書かないでください。書いた場合もチェック機能が警告します。

## 2. 投稿案を一括作成する

```bash
python3 salon.py generate salon-a --plan trial      # お試し 4投稿
python3 salon.py generate salon-a --plan monthly    # 継続 8投稿
```

- 投稿予定日は「次の月曜から週2回」です。指定するときは `--start 2026-11-02` を付けます。
- 毎回 `clients/salon-a/orders/日付-プラン/` に次のファイルができます。

| ファイル | 用途 |
|---|---|
| `posts.csv` | **編集する元データ**（Excel・Googleスプレッドシートで開ける） |
| `確認用.md` | 読みやすい確認用（警告・要確認事項つき）。社内用なので店舗には送らない |
| `status.json` | 制作状況の記録（手で編集しない） |

2回目以降の注文では、紹介するメニューの順番が自動でずれます。

---

## 3. 確認・修正する（ここが一番大事）

1. `確認用.md` を読みます。
   - **⚠ 表現チェック**：`[NG]` は書き換えが必要、`[注意]` は根拠や条件の確認が必要です。
   - **要確認事項**：料金未入力・写真の許諾など、店舗に確認することです。
2. `posts.csv` を開いて文章を直します。
3. 1投稿ずつ読み、問題がなければ **「人間確認」列を `済`** にします。
4. もう一度チェックします。

   ```bash
   python3 salon.py check salon-a
   ```

- NG判定でも問題ないと判断した場合（店名に「治療院」が入る等）は、「確認メモ」列に `表現確認済：理由` と書くと先へ進めます。
- 本文に `【要確認：…】` が残っていると納品できません。店舗に確認して書き換えてください。

### （任意）文章をもっと自然にしたいとき

```bash
python3 salon.py prompt salon-a
```

`整文用プロンプト.txt` ができます。すでに使っている Claude（claude.ai など）に貼り付けると、事実を足さずに文章を整えるよう依頼できます。返ってきた文章を `posts.csv` に反映し、もう一度 `check` を実行してください（新しい表現もチェックされます）。

## 4. 納品データを作る

```bash
python3 salon.py deliver salon-a
```

全投稿が「人間確認＝済」で、NG表現と【要確認】が残っていないときだけ、`納品/` フォルダができます。

| ファイル | 中身 |
|---|---|
| `納品資料.md` | 店舗向けの投稿案一式（確認のお願い・確認事項つき） |
| `投稿一覧.csv` | 投稿予定日・見出し・画像構成・キャプション・ハッシュタグ（社内メモは含まない） |
| `canva一括作成用.csv` | 見出し・スライドごとの文字（Canvaに貼る用） |

あわせて、誰がいつ確認したかの記録が `チェック記録.md` に残ります。

### Canva での画像づくり

- **基本（無料プランでOK）**：お気に入りのテンプレートを1つ決め、`投稿一覧.csv` の「画像構成案」を見ながら文字をコピー＆ペーストします。4投稿なら20〜40分ほどが目安です。
- **一括作成（Bulk Create）が使える場合**：`canva一括作成用.csv` をアップロードし、テンプレートの文字枠と列（見出し・スライド1…）をつなげると、まとめて作れます。プランによっては使えないため、必須にはしていません。
- 写真は `photos/` にある、店舗から許諾を得たものだけを使います。

## 5. 制作状況を管理する

```bash
python3 salon.py status
```

全顧客・全注文の状況を一覧表示し、`clients/制作状況.md` にも保存します。

状態は次の順に進みます。

`下書き作成済 → 自己確認中 → 納品データ作成済 → 顧客確認待ち →（修正中）→ 納品済 → 入金確認済`

最初の3つは自動で更新されます。店舗に送った後などは手で更新します。

```bash
python3 salon.py set-status salon-a 顧客確認待ち
python3 salon.py set-status salon-a 納品済 --note "LINEで送付"
python3 salon.py set-status salon-a 入金確認済
```

※ 納品データを作る前は「顧客確認待ち」以降にできません。

## 6. 毎日の作業の目安（15〜30分）

| 時間 | 作業 |
|---|---|
| 2分 | `python3 salon.py status` で今日やることを確認 |
| 10〜20分 | 1〜2投稿分を確認・修正し、「人間確認」を `済` にする |
| 5分 | `check` を実行し、警告と要確認事項を店舗への質問リストにまとめる |

お試し4投稿は、ヒアリング30分＋生成1分＋確認・修正40分＋Canva 40分ほどで納品できる想定です。

---

## 7. 守ること（ルール）

- **投稿は必ず人間が確認してから**。公開するかどうかは店舗が判断します。このツールはInstagramに投稿しません。
- **効果・料金・口コミ・実績を作らない**。ツールは店舗情報に書かれたことだけを使います。
- **表現チェックは機械的な注意喚起**です。法的な判断ではないため、迷う表現は使わないか、店舗に確認してください。
- **写真・個人情報**
  - `clients/` フォルダは `.gitignore` に入れてあり、GitHubには上がりません。消さないでください。
  - このリポジトリは GitHub Pages で公開されている可能性があります。顧客データを `clients/` 以外に置かないでください。
  - 写真のファイル名に個人名を入れない、お客様が写った写真は本人同意を取る、契約終了後は決めた期間で削除する、を守ります。
  - パソコンのバックアップは、共有設定のないクラウドフォルダか外付けディスクに取ります。

## 8. テスト（開発者向け）

```bash
python3 -m unittest discover -s tests -v
```

## ファイル構成

```
salon-insta/
├── salon.py                    操作コマンド
├── salontool/
│   ├── config.py               店舗情報の読み込み・入力チェック
│   ├── generator.py            投稿案の作成
│   ├── checker.py              表現チェック（NG/注意のルールはここに追加）
│   └── orders.py               保存・確認・納品・状況管理
├── templates/client_template.toml   店舗情報のひな形
├── samples/sample_salon.toml        架空サロンの設定
├── samples/output/                  架空サロンの生成例
├── tests/                           自動テスト
└── clients/                         顧客データ（GitHubに上げない）
```
